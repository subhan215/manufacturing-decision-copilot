# Product Brief: Botanical Renewal Vitamin C Face Serum

**Document ID:** PB-2026-0142
**Version:** 1.0 (frozen)
**Requesting team:** Product & Sourcing, SkinLumen Cosmetics
**Product category:** Skincare — liquid serum, glass dropper bottle format

## 1. Product summary

A 30ml Vitamin C brightening face serum, aqueous-alcohol base, packaged in an amber glass dropper bottle with a tamper-evident seal. Target initial order: **8,000 units** for a regional retail launch, with an option to scale to 40,000 units/quarter if the launch succeeds.

## 2. Mandatory requirements (hard constraints)

A supplier **must** satisfy every item below to be eligible. Any single failure disqualifies the supplier regardless of performance elsewhere.

| # | Requirement | Rationale |
|---|---|---|
| MR-1 | Manufacturing capability: documented experience producing **liquid/serum skincare formulations** (not solid or powder cosmetics only) | Serum filling requires liquid-fill line capability, distinct from solid-format cosmetics |
| MR-2 | Holds a current **ISO 22716 (Cosmetics GMP)** certification | Regulatory baseline for cosmetics manufacturing; non-negotiable for retail listing |
| MR-3 | Minimum order quantity (MOQ) accepted is **≤ 5,000 units** for a first order | Initial order is 8,000 units; supplier must be willing to accept an order in that range without forcing a much larger commitment |
| MR-4 | Historical quality inspection **fail rate ≤ 30%** across audited production batches | Reject rate above this threshold indicates unacceptable process variability for a new retail product |
| MR-5 | Manufacturing lead time **≤ 20 calendar days** | Needed to hit the planned retail launch window |
| MR-6 | Facility located in **India** (for this sourcing round) | Import/logistics timeline for this launch phase is scoped to domestic manufacturing only; cross-border sourcing is out of scope for this decision |
| MR-7 | Provides documented **cruelty-free** manufacturing declaration | Required for brand positioning and retail partner compliance |

## 3. Ranking priorities (used after eligibility screening, for suppliers that pass all mandatory requirements)

These are the *soft* criteria used to rank eligible suppliers. Default weights are shown; the sensitivity analysis in the prototype must show how the ranking changes when these weights are adjusted.

| Priority | Default weight | Signal source |
|---|---|---|
| Unit manufacturing cost | 35% | Manufacturing costs field |
| Manufacturing lead time | 25% | Manufacturing lead time field |
| Quality track record (inverse of fail rate) | 25% | Inspection results history |
| Sustainability score (cruelty-free + any additional certifications) | 15% | Supplier profile document |

## 4. Known ambiguity to expect in supplier data

Not all supplier profiles are clean. Some contain missing fields, conflicting certification dates, or self-reported figures that differ from audited figures. The prototype must surface these conflicts rather than silently resolving them — this is intentional and mirrors the real-world state of sourcing documentation described in the challenge brief.

## 5. Out of scope

This brief does not authorize contacting any supplier, requesting a live quotation, or placing an order. It supports an internal sourcing decision only; any outward action requires separate human approval.
